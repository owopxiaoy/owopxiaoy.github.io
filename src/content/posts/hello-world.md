今天，我终于有了自己的博客。

搭建页面的时候，总想着把颜色、头像和布局调整到满意再开始写。后来发现，**真正让博客成为我的博客的，是我写下的内容。**

所以，就从这篇简单的记录开始吧。

## 为什么想写博客

我想给零散的想法找一个地方，也想把学习过程中遇到的问题和解决方法留下来。

这里不一定每篇都是完整的教程。有时候，它可能只是一次调试记录、一段读书笔记，或者一个突然冒出来的念头。

> 不必等到完全掌握一件事，才开始记录它。

## 顺便练习 Markdown

Markdown 的好处是，可以用简单的文字标记表达结构，把注意力留给内容。

### 强调文字

我可以用 **粗体** 标记重点，用 *斜体* 表示强调，也可以用 ~~删除线~~ 留下修改痕迹。

如果提到文件名或短命令，可以使用行内代码，例如 `src/content/posts/` 和 `pnpm dev`。

### 添加链接

这个博客使用了 [Fuwari 模板](https://github.com/saicaca/fuwari)。

链接的写法是：

```markdown
[显示给读者的文字](https://example.com)
```

### 插入图片

图片适合用来记录项目成果、展示过程，或者为文章留下一点生活气息。

例如，在这篇文章旁边新建一个 `images` 文件夹，把图片命名为 `my-desk.jpg`，就可以使用下面的写法：

```markdown
![我的书桌](./images/my-desk.jpg)
```

<!-- 这里故意把图片语法放在代码块中，因此还没有图片时也不会产生失效图片。 -->
<!-- 准备好真实图片后，把图片语法复制到代码块外面即可。 -->

### 展示代码

代码块用三枚反引号包围，在开头注明语言，可以帮助读者理解代码。

```python
def say_hello(name):
    return f"你好，{name}！欢迎来到我的博客。"

print(say_hello("朋友"))
```

这个小程序会输出：

```text
你好，朋友！欢迎来到我的博客。
```

### 用表格整理信息

| 内容类型 | 我想记录的重点 | 一个例子 |
| --- | --- | --- |
| 学习笔记 | 概念与理解 | 第一次理解闭环控制 |
| 项目实践 | 问题与解决过程 | 机器人调试记录 |
| 日常记录 | 当时的观察和感受 | 我的第一篇博客 |

## 如何把这篇文章变成下一篇

以后写新文章时，我可以复制这个文件，给它起一个新的英文文件名，例如 `my-second-post.md`，然后：

1. 修改顶部的标题、日期和简介。
2. 设置适合内容的 `tags` 和 `category`。
3. 保留需要的段落格式，替换正文。
4. 在本地预览，检查图片、链接与排版。

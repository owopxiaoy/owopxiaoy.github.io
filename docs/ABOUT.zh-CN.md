# 更新“关于”页面

## 增加生活照片

1. 把 JPG、PNG 或 WebP 照片放进 `src/assets/life/`。
2. 推荐命名为 `05-周末散步.jpg`，数字控制顺序，后面的文字会显示为照片说明。
3. 页面会自动收集该文件夹的照片，不需要修改代码。
4. 删除对应图片即可从相册移除；同名替换可更新照片。
5. 本地预览后，将图片和相关修改提交、推送，等待自动部署完成。

这里是静态博客，网页没有在线上传后台；新增入口就是上述本地文件夹。
